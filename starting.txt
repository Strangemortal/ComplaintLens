This is much more than a CRUD application. It's an **AI Agent application** that mimics how pharmaceutical companies manage product complaints inside a **Quality Management System (QMS)**. 

The assignment is testing whether you can build an **AI-first workflow**, not just a React + FastAPI project.

---

# What is the actual problem?

Imagine Pfizer, Cipla, Sun Pharma, Dr. Reddy's, etc.

A pharmacy sends an email:

> "We received 15 boxes of Paracetamol 500 mg tablets. Batch PCM24015 appears discolored. Manufacturing date Jan 2026. Expiry Dec 2028. Approximately 300 strips affected."

Normally a QA executive manually reads the email and enters information into a complaint system.

That takes time.

Instead, AIVOA wants AI to:

* read the complaint
* understand it
* extract information
* fill the complaint form
* assess the risk
* suggest next actions

without manual typing.

# Mandatory Feature 1

## Log Complaint

Suppose the user types

> "A pharmacy reported that Paracetamol 500 mg tablets from batch PCM24015 are discolored. Around 300 strips are affected. Manufactured January 2026 and expires December 2028."

AI should automatically produce

| Field    | Value       |
| -------- | ----------- |
| Product  | Paracetamol |
| Strength | 500 mg      |
| Batch    | PCM24015    |
| Quantity | 300         |
| MFG      | Jan 2026    |
| EXP      | Dec 2028    |

WITHOUT asking the user to fill each field.

---

Then AI should also generate

Risk Assessment

```
Severity:
Major

Reason:
Product discoloration may indicate degradation.

Impact:
Potential patient safety concern.

Recommended Action:
Route to QA Investigation.
Replace stock.
Hold remaining inventory.
```

Notice:

Nobody explicitly told AI

> Severity = Major

AI must reason that itself.

---

# Mandatory Feature 2

## Edit Complaint

Suppose after logging the complaint, user says

> Batch number is PCM24018 instead.

AI updates only

```
Batch Number

PCM24015
↓

PCM24018
```

Everything else stays the same.

---

Then user says

> Quantity is actually 520 strips.

Only quantity changes.

---

Then

> Manufacturing date is February instead.

Only MFG changes.

This is basically

AI + State Management

instead of

Replace everything.
